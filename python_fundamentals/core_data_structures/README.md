# Python - Core Data Structures

This directory contains Python exercises about lists and other core data structures, including looping over their elements and printing them with string formatting.

## Files

| File | Description |
|------|-------------|
| `print_list_integer.py` | Prints all integers of a list, one per line |
| `replace_in_list.py` | Replaces an element of a list at a given index |
| `print_matrix_integer.py` | Prints a matrix of integers, one row per line |
